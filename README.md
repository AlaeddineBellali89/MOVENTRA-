# MOVENTRA
Train. Recover. Return Stronger.

Flutter MVP for Android and iOS.

## Current prototype
- Today dashboard
- Body check-in
- Adaptive workout demo
- Recovery
- Progress

## GitHub Android build
The included GitHub Actions workflow builds a debug APK. Open Actions > Build Android APK > Run workflow. When complete, download the `moventra-debug-apk` artifact.

## Safety
Prototype only. MOVENTRA does not diagnose injuries or replace a doctor or physiotherapist. Clinical rules, red-flag triage, GDPR/privacy, and EU medical-device implications require professional review before launch.
